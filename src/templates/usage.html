Query Usage Guide

Learn how to construct powerful search queries for humans and automated agents.

For Humans: Search Syntax

Type these special commands directly into the search bar to refine your results.

Command Description Example
!category Search only engines in a specific category. !tor hidden services (Searches Ahmia)
!engine Search only a specific engine. !github rust crates
:lang Filter results by language code. python tutorial :en or :de
<N Set a custom timeout (seconds or ms). news <3 (3 seconds) or <850ms
!! Redirect to the first search result immediately. !! weather
!safesearch Enable strict safe search. images !safesearch
!day, !week, !month, !year Filter results by time range. tech news !week

For Agents: HTTP API

Automated tools can query the engine via the JSON API.

Endpoint

GET /search?q={query}&format=json

Parameters

  • q: The search query string (required).
  • format: Output format. Use json for agents.
  • categories: Comma-separated list of categories (e.g., general,news).
  • engines: Comma-separated list of engine names (e.g., google,duckduckgo).
  • language: Language code (e.g., en, de).
  • safesearch: 0 (off), 1 (moderate), 2 (strict).
  • time_range: day, week, month, year.
  • pageno: Page number (default: 1).

Example Request (cURL)

curl "http://127.0.0.1:8888/search?q=artificial+news&format=json&categories=general,news&language=en"
